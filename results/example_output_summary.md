# Example output summary

This folder is intended for small summary files only.

Large intermediate files such as BAM, BAI, VCF, GVCF, and snpEff output files are not tracked in this repository.

Expected final outputs:

- `final.filtered.vcf.gz`
- `final.filtered.vcf.gz.csi`
- `final.ann.vcf`
- `snpEff_summary.html`
